# Entrega académica — Coderhouse

Esta carpeta contiene **la entrega de Citi Bike Demand Intelligence para Coderhouse**, separada de la estructura principal de desarrollo del proyecto.

## Archivos

- [Notebook académico (.ipynb)](Citi_Bike_Coderhouse_Entrega_Academica.ipynb): versión condensada para evaluación, con hipótesis, gráficos, interpretación y conclusiones. Usa los archivos procesados disponibles en `../../data/processed/`.
- [Presentación ejecutiva (.pptx)](Citi_Bike_Presentacion_Ejecutiva_Coderhouse.pptx): 11 diapositivas con los principales hallazgos, implicaciones operativas y próximos pasos.

## Proyecto principal

La versión de trabajo completa se mantiene en [`notebooks/01_data_acquisition_preparation.ipynb`](../../notebooks/01_data_acquisition_preparation.ipynb) y [`notebooks/02_eda_insights.ipynb`](../../notebooks/02_eda_insights.ipynb), junto con los datasets, dependencias y documentación del repositorio.

> **Carpeta temporal:** se mantiene únicamente para la evaluación de Coderhouse. Al finalizar la cursada puede eliminarse por completo sin modificar el pipeline, los notebooks principales ni los datasets del proyecto.

**Nota:** El notebook académico condensado tiene código reproducible y gráficos de referencia; las salidas de ejecución no se incluyen en las celdas. Para ejecutar el análisis, instalá `../../requirements.txt` y usá los CSV procesados del repositorio.
